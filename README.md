# Kashiwazaki SEO StayPop

![WordPress](https://img.shields.io/badge/WordPress-6.0%2B-blue.svg)
![PHP](https://img.shields.io/badge/PHP-7.4%2B-purple.svg)
![License](https://img.shields.io/badge/License-GPL--2.0--or--later-green.svg)
![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)

訪問者がページから離れそうになった瞬間に、バナーやポップアップを表示して、購入・問い合わせ・登録などへの次の一歩を案内する WordPress プラグインです。いつ・どこに・だれに表示するかを細かく決められ、表示・クリック・成果の回数を集計して比べられます。

## 主な機能

| 機能 | 説明 |
| --- | --- |
| 離れそうな瞬間に表示 | PC はマウスが画面の上端から外に出たとき（感度・待ち時間を設定）、スマホは下に読んだあと上に戻るスクロールをしたときに表示します。 |
| そのほかのきっかけ | ページを ○ 秒見たとき・○ ％までスクロールしたときも選べます。「どれか1つ」「すべてそろったとき」の組み合わせに対応します。 |
| 読むのをじゃましない | ページを開いてから ○ 秒の間、マウスを少し動かしただけのとき、フォームに入力している間（入力のあと 10 秒も）は表示しません。見送ったきっかけを、あとからまとめて表示することはありません。 |
| 表示するページ | サイト全体、または URL・パス・投稿・固定ページ・カテゴリーで指定したページだけ。購入完了・決済のページなどは除外できます。 |
| 回数・期間・優先度 | 1回の訪問につき1回まで・1日1回まで・最初の1回だけ・ページを開くたびに。閉じたあと ○ 日は表示しない設定、掲載期間、優先度（重なったときは1つだけ表示）。 |
| 出し分け | ログイン状態・ユーザーの権限・流入元（utm_source）・参照元のサイトで絞り込みます。 |
| 内容 | 画像（メディアライブラリ）・スマホ用の画像・見出し・説明文・ボタン・小さなサブリンク。クーポン・資料請求・LINE登録・関連記事・問い合わせ誘導のテンプレートつき。 |
| デザイン | 中央ポップアップ・下部バナー・隅からのスライド表示。幅（PC・スマホ）・色・角の丸み・余白・文字の大きさ・背景の暗さ。 |
| 編集画面 | タブで項目を切り替え、右のプレビューで PC・スマホ・A/B の見た目をすぐに確認。「実物大で見る」にも対応します。 |
| サイトでテスト表示 | 保存したバナーをサイトのトップページで試せます。画面の左下に、あと何をすれば表示されるかが出ます（記録はしません）。 |
| 成果と A/B テスト | 成果ページに来た人を数え、見出し・ボタンの文言・画像の違う2つのパターンを決めた割合で出し分けて比べます。 |
| 集計 | 表示・クリック・閉じた・成果の回数と、クリック率・成果率を、バナー別・パターン別・端末別・ページ別に表示します（直近 7・30・90 日）。 |
| プライバシー | 計測のオン・オフ、同意した人だけ記録する設定（同意の Cookie と連携）、トラッキング拒否（Do Not Track）の尊重、ログの自動削除。 |
| アクセシビリティ | キーボードの操作の位置（フォーカス）の移動と復帰、Esc で閉じる、中央ポップアップ内での Tab の移動、動きを減らす設定への対応。 |
| 移行・バックアップ | すべてのバナーと設定をファイルに書き出し、別のサイトで読み込めます（読み込んだバナーは停止中で追加）。 |

## インストール

1. このリポジトリのフォルダ `wp-plugin-kashiwazaki-seo-staypop` を `wp-content/plugins/` に配置します（または ZIP を「プラグインのアップロード」からインストールします）。
2. 管理画面の「プラグイン」から「Kashiwazaki SEO StayPop」を有効化します。
3. 左メニューに「Kashiwazaki SEO StayPop」が追加されます。

## 使い方

1. 左メニュー「Kashiwazaki SEO StayPop」を開き、「バナーを追加」を押します。
2. 管理用の名前を入れ、「内容」タブで見出し・説明文・ボタンの文言とリンク先を入れます。
3. 「デザイン」「表示のタイミング」「表示するページ」「回数・期間」「出し分け」「成果・A/Bテスト」の各タブで、必要な項目を決めます。右のプレビューで見た目を確かめます。
4. 「公開」を押します（「サイトに表示する」がオンなら表示が始まります）。
5. 「サイトでテスト表示」で、サイトで実際に表示されることを確かめます。
6. 「集計」タブで、表示・クリック・成果を確かめます。

画面ごとの詳しい説明は [マニュアル](docs/index.html) を参照してください。

## 動作対象

公開ページ（フロントエンド）のみ。バナーを表示する候補があるページと、成果を数えるページだけでスクリプトとスタイルを読み込みます。
