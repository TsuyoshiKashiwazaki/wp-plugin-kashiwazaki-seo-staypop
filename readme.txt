訪問者がページから離れそうになった瞬間に、バナーやポップアップで購入・問い合わせ・登録への次の一歩を案内します。

== Description ==

Kashiwazaki SEO StayPop は、ページから離れそうな訪問者にバナーやポップアップを表示して、購入・問い合わせ・登録などの行動を後押しするプラグインです。表示は「きっかけ」が起きたその瞬間だけで、ページを開いた直後や入力中は見送ります。いつ表示されるかは、管理画面に文章で表示されます。

= 主な機能 =

* **離れそうな瞬間に表示** … PC はマウスが画面の上端から外に出たとき（感度・待ち時間を設定）、スマホは下に読んだあと上に戻るスクロールをしたとき。
* **そのほかのきっかけ** … ページを ○ 秒見たとき、○ ％までスクロールしたとき。「どれか1つ」「すべてそろったとき」を選べます。
* **読むのをじゃましない** … 開いてから ○ 秒の間、マウスを少し動かしただけのとき、フォームに入力している間は表示しません。
* **表示するページ・表示しないページ** … サイト全体、または URL・パス・投稿・固定ページ・カテゴリーで指定。購入完了・決済のページなどは除外できます。
* **回数・期間・優先度** … 1回の訪問につき1回まで・1日1回まで・最初の1回だけ・ページを開くたびに。閉じたあと ○ 日は表示しない設定、掲載期間、優先度。
* **出し分け** … ログイン状態・ユーザーの権限・流入元（utm_source）・参照元のサイト。
* **内容とデザイン** … 画像（メディアライブラリ）・スマホ用の画像・見出し・説明文・ボタン・サブリンク。中央ポップアップ・下部バナー・隅からのスライド表示、幅・色・角の丸み・余白・文字の大きさ・背景の暗さ。
* **テンプレート** … クーポン・資料請求・LINE登録・関連記事・問い合わせ誘導。
* **タブとプレビューの編集画面** … PC・スマホ・A/B の見た目を保存前に確認でき、「実物大で見る」にも対応。
* **サイトでテスト表示** … 保存したバナーをサイトで試せます。あと何をすれば表示されるかが画面に出ます（記録はしません）。
* **成果と A/B テスト** … 成果ページに来た人を数え、2つのパターンを決めた割合で出し分けて比べます。
* **集計** … 表示・クリック・閉じた・成果、クリック率・成果率をバナー別・パターン別・端末別・ページ別に表示。
* **プライバシー** … 計測のオン・オフ、同意した人だけ記録する設定、トラッキング拒否の尊重、ログの自動削除。
* **アクセシビリティ** … フォーカスの移動と復帰、Esc で閉じる、動きを減らす設定への対応。
* **移行・バックアップ** … すべてのバナーと設定の書き出し・読み込み。

= 動作対象 =

公開ページ（フロントエンド）のみ。バナーを表示する候補があるページと、成果を数えるページだけでスクリプトとスタイルを読み込みます。

== Installation ==

1. プラグインのフォルダ `wp-plugin-kashiwazaki-seo-staypop` を `wp-content/plugins/` に配置するか、ZIP を「プラグインのアップロード」からインストールします。
2. 「プラグイン」から「Kashiwazaki SEO StayPop」を有効化します。
3. 左メニューの「Kashiwazaki SEO StayPop」を開き、「バナーを追加」から最初のバナーを作ります。
4. 内容・タイミングなどを決めて「公開」し、「サイトでテスト表示」で確かめます。

== Frequently Asked Questions ==

= バナーが表示されません =

バナー一覧の「状態」が「表示中」か、「表示のタイミング」に「表示されません」と出ていないかを確かめてください。表示する回数や閉じたあとの日数はブラウザごとに数えるため、一度表示されたあとは同じブラウザでは表示されないことがあります。確認には「サイトでテスト表示」を使ってください。

= ページの表示が崩れませんか？ =

バナーはきっかけが起きたときに画面へ重ねて表示するもので、ページの本文は変更しません。

= 計測を止めたい =

「設定」タブで「計測」をオフにするか、「同意した人だけ記録する」を選んでください。

= プラグインを削除するとデータはどうなりますか？ =

プラグインを削除すると、すべてのバナー・設定・集計のログが削除されます。必要なら先に「設定」タブの「書き出し」で控えを取ってください。
